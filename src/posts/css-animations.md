# CSS Animations: Creativiteit in Beweging  
*We Love Web sessie door Julia Miocene*

Op 15 december 2023 woonde ik een inspirerende We Love Web-lezing bij van **Julia Miocene**, UX engineer bij GitLab, Google Developer Expert en ambassadeur voor TechWomen. Sinds 2017 heeft zij zich gespecialiseerd in het maken van geavanceerde en speelse CSS-animaties, en tijdens haar sessie nam ze ons mee in de wereld van visuele expressie met slechts HTML en CSS.

---

## Van Simpel naar Geavanceerd

Julia liet zien hoe je met een paar HTML `<div>`-elementen en slim gebruik van **CSS custom properties** indrukwekkende animaties kunt maken. Haar werk beweegt zich tussen eenvoudige micro-animaties en volledige cartoon-stijl animaties – allemaal zonder JavaScript.

Ze benadrukte het belang van:

- **Nieuwe dingen blijven leren**
- **Plezier hebben tijdens het creëren**
- **Vaardigheden uitbreiden via experimenteren**
- **Je aansluiten bij een creatieve community**
- **Technologische grenzen verleggen**

> “CSS is niet beperkt tot UI-animaties. Het is een medium voor expressie.”

---

## De Geschiedenis van Animatie in Context

Julia plaatste CSS-animatie in historisch perspectief en liet zien hoe de evolutie van animatie samenloopt met technologische ontwikkelingen:

- **1900** – Eerste cartoon  
- **1917** – Eerste animatiefilm  
- **1928** – Eerste Disney cartoon  
- **1962** – Eerste videogame  
- **1991** – Eerste computer-game met geavanceerde visuals  
- **1996** – De geboorte van CSS  

CSS biedt sinds zijn ontstaan steeds meer creatieve mogelijkheden, waarbij moderne browsers nu complexe visuele effecten ondersteunen – vaak met verrassend weinig code.

## Waarom zou je CSS-animatie leren?

Naast dat het technisch interessant is, biedt CSS-animatie ook mentale en creatieve voordelen:

- 🎯 **Blijf leren** en ontdek nieuwe technieken  
- 😄 **Voorkom burn-out** door speelse side-projects  
- 🧰 **Verbreed je skillset** als frontend developer  
- 🤝 **Vind een creatieve community** van makers  
- 🚀 **Stuw technologie vooruit** met experiment en expressie

## Tot Slot

Julia's sessie was niet alleen een technisch kijkje in de mogelijkheden van CSS, maar vooral ook een oproep tot creativiteit. CSS is méér dan styling – het is een canvas voor expressie, en het vereist niets meer dan wat HTML, een paar regels code en een flinke dosis verbeelding.

> **“CSS is powerful, expressive and fun — use it to create art.” – Julia Miocene**
